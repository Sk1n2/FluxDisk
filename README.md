# FluxDisk

USB repair tool for recovering hidden files, fixing write protection and restoring damaged USB drives.

![FluxDisk Screenshot](FluxDisk1.0.PNG)

## Features

- Recover hidden files and folders
- Repair soft write protection
- Fix filesystem errors
- Detect missing USB devices
- Restore damaged USB drives
- Erase and recreate USB partitions
